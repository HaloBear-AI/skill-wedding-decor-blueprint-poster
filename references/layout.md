# 展板版式和验收

默认使用白底 2160 × 2880 px，3:4 竖版。下表以左上角为原点，位置单位为像素。导出其他 3:4 尺寸时等比缩放。

| 分区 | 默认位置 | 排版 |
| --- | --- | --- |
| 品牌页眉 | 左上，x 80–2080、y 48–148 | Logo 框 100 × 100，图标等比呈现。品牌名 56 px。两项均缺省时，保留顶部留白 |
| 标题与副标题 | x 124–2080、y 214–407 | 左侧强调色竖线。标题 70 px，副标题 41 px，各最多两行 |
| 左侧主视觉 | x 80–1290、y 474–1328 | 白页上的浅色底框。默认等比留白保留整张图，`--hero-fit cover` 使用居中满框裁切 |
| 正立面 | 右栏顶部，x 1360–2080、y 439–849 | 小节标题 48 px。图稿框 x 1510–2065、y 517–765，左侧标 H、下方标 W |
| 平面布置 | 右栏下部，x 1360–2080、y 856–1408 | 图稿框 x 1360–1942、y 935–1323，右侧标 D、下方标 A |
| 主要物料 | x 80–826、y 1440 至约 2164 | 标题下接两列表格。表头 33 px，单元格约 32 px，5 至 8 行 |
| 主要组件 | x 884–2080、y 1440–2157 | 三列两行，格间距 26 px，白底单体，名称 35 px，居中 |
| 布置顺序 | x 80–2080、y 2225–2742 | 五列等宽，格间距 46 px。依次排圆点编号、步骤名、图和两行以内简述。列间为方向箭头 |
| 页脚 | x 80–2080、y 2794–2846 | 右对齐，27 px，从 `labels.disclaimer` 取文案 |

字号为排版上限。Pillow 测量字符实际占用面积，在各框内换行及缩小字号，保留完整文案。提交前以常用查看尺寸复核带极长标题及配置说明的展板。

## 实显文案

- 主标题按 `theme` + `·` + `labels.title_suffix` 拼接，副标题以 ` / ` 连接三个 `subtitle_elements`。
- 视图标题取各自的 `heading`。尺寸文字为 `label`、对应的大写字母和括号中的尺寸值。中文示例为「总高 H（待实测）」，非中文使用半角括号。H、D 可上下分行。值为空时用 `labels.pending_measurement`。
- 物料表题与表头分别取 `labels.materials`、`labels.material_name`、`labels.material_detail`，行内取各项名称和配置说明。组件标题与步骤标题从相应 `labels` 取值，按数组顺序呈现部件名和步骤编号、名称、简述。
- 占位块同时显示 `labels.missing_asset` 及对应的视图、部件或步骤名称。Logo 和主图内的原有文字视为源图像素。

## 图像、颜色和字体

- 插画的浅白外边距可被裁掉，再按比例适配各区域。若抠图带透明边，合成在白底上。平面图的 A 标线有 `aisle_span` 时按其两个比例定位，否则使用居中的示意位置。箭头与图稿之间留有间隙。
- 纵向标线和横向标线取图稿显示范围，箭头表达尺寸的指向。标线坐标、图像物件大小与实测值彼此独立。
- 默认从原图采样一个强调色，也可使用 `palette.accent`。必要时调深强调色，以保证白底上的标题和圆内白字具有对比。正文使用近黑色，表格边线和占位底保持浅色。
- 字体依次查找 `--font`、`assets/fonts/`、系统常用中日韩字体路径。检查字体是否覆盖实显文字。右到左文字需要 Pillow 的 libraqm 支持。

## 验收清单

1. 确认 PNG 为 3:4，核对左主图、右上正立面与右下平面、中段物料与组件、底部五步及页脚的位置。
2. 与原图核对造型、色系、左右和前后关系。检查正立面视角、俯视角度、白底组件和五步渐进关系。
3. 核对所有文字，缺省品牌时检查页眉留白。查 H、W、D、A 的字母、数值来源、单位、待实测显示及通道标线位置。
4. 放大核对行内字符、对齐与重叠情况，确认各图无水印、尺寸线或文字侵入。发现白边或主体越界时，回到子图素材调整。
5. 核对合成命令的占位清单。缺图时按清单交代每个需要补齐的文件，复用当前规格、原图和子图路径重新合成。
