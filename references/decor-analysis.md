# 场布分析和规格填写

把同一张原图中可辨认的构造和用户确认的数据写入 `decor-spec.json`。字段和上限以随包规格为准。[字段定义](../assets/decor-spec.schema.json) · [可校验的示例](../assets/example/decor-spec.json)

## 从原图记录证据

1. 先看全图。确定仪式区、舞台或迎宾区等场景，记录主背景中心、可见地台轮廓、花艺的高低与疏密、通道和装饰物的相对位置。保留参考图里的左右方向、非对称关系、形状和色彩。
2. 再看关键局部。根据边缘、反光、纹理、垂坠和安装痕迹描述可见表面。色彩用可对照的描述，如象牙白、暖金、灰粉。花种、基材、固定方式或背面看不清时，使用可见的花型和表面特征。详情可写「基材待确认」或「背面待确认」。
3. 转成正立面和平面。正立面取面向主体的可见轮廓和高度关系。平面用俯视示意保留前后、左右及动线关系。将遮挡处留白，图示范围以可见证据为限。支撑结构、遮挡区陈设、采购数量和施工做法均需另有资料才能写入。
4. 定出六个可辨识的部件槽位。优先取轮廓清楚、能传达方案的部件，例如背景板、垂挂布幔、主花艺、地台、通道饰面和花器。同类部件可按原图清晰可见的不同位置拆分。资料不足的槽位用「待确认部件」或实际可对照的名称，`prompt_detail` 置 `null`。
5. 组织五步搭建顺序。按方案沟通所需概括可见工序，描述对应成品部位。步骤图只画原图能支持的状态。缺乏可画依据的步骤仍保留本地化名称和简述，`prompt_detail` 置 `null`。

## 规格字段

使用 UTF-8 JSON，`schema_version` 填整数 `1`。全部文字填单行，并去掉首尾空白。未知尺寸与未知插画使用 JSON 值 `null`。按实际字段写入，扩展说明单独放在交付说明中。

| 字段 | 填写方式 |
| --- | --- |
| `language` | 默认 `zh-CN`，按成品语言填写语言标签，例如 `en`。标题、标签、尺寸名称、材料、部件、步骤和页脚文案都使用该语言，专名沿用用户给定拼写。标签最长 35 字符。 |
| `theme` | 使用用户给出的主题。未指定时从场景主色、形态或空间气质拟题，中文通常约四字。最长 96 字符。 |
| `brand_name` | 选填，最长 48 字符。以用户指定的品牌名为准，缺少时省略或写 `null`。Logo 文件由 `--logo` 单独传入。 |
| `palette.accent` | 选填，使用六位 `#RRGGBB`。省略 `palette` 时由排版脚本从原图导出深强调色。 |
| `subtitle_elements` | 恰好三项，选场地特征、主色、花艺或空间要素等可见关键词。每项最多 24 字符。 |
| `labels` | 写全下表九项。使用简短、可在卡片中阅读的文字。 |
| `views` | 写全 `elevation` 和 `plan`。两张图分别记录标题和可画依据。 |
| `views.elevation` | `heading` 最长 32 字符。`prompt_detail` 描述正立面视角下可见轮廓、相对高度、层次和色彩，最长 480 字符或 `null`。 |
| `views.plan` | `heading` 最长 32 字符。`prompt_detail` 描述俯视示意范围、可见物件的前后左右关系和通道，最长 480 字符或 `null`。可选 `aisle_span` 见下文。 |
| `dimensions` | 写全 `H`、`W`、`D`、`A`。每项包含 `label`（最多 20 字符）和 `value`（最多 24 字符或 `null`）。 |
| `materials` | 5 至 8 项。每项包含 `name`（最多 24 字符）和 `detail`（最多 48 字符）。按结构、表面和颜色短写。可见材料少时按可区分的部位分行，仍缺的项目写与可见构件有关的待确认项。 |
| `components` | 正好 6 项，按成品顺序填写。每项包含 `name`（最多 24 字符）和 `prompt_detail`（最多 300 字符或 `null`）。 |
| `steps` | 正好 5 项。每项包含 `number`、`name`、`description` 和 `prompt_detail`。`number` 按整数 1 至 5 排列。名称最多 24 字符，简述最多 54 字符，绘图描述最多 480 字符或 `null`。 |

| `materials` | 主要物料 | 28 |
| `material_name` | 组件 | 20 |
| `material_detail` | 配置说明 | 26 |
| `components` | 主要组件示意 | 32 |
| `steps` | 布置顺序示意 | 32 |
| `pending_measurement` | 待实测 | 16 |
| `missing_asset` | 待补图 | 22 |
| `disclaimer` | 示意图，非施工图，尺寸以现场实测为准 | 100 |

### 尺寸与通道

`H` 为主体总高，`W` 为主体总宽，`D` 为场地进深，`A` 为通道净宽。根据场景写明测量对象，例如「背景高度」和「仪式通道净宽」。用户明确提供数值时，填写单个正数和单位，如 `"2.4 m"` 或 `"240 厘米"`。支持 `mm`、`cm`、`m`、`in`、`ft`、毫米、厘米、公分、米、英寸、英尺。仅有照片时用 `null`；带约数、范围、面积或多轴值的文字留在交付说明中。

对平面图确定有可见通道时，可填 `views.plan.aisle_span`。先去掉平面缩略图外部白边，再以裁去白边的图稿宽度为基准，将通道近端左缘、右缘各换算成 x 坐标，图稿最左为 `0`，最右为 `1`。两个值严格递增，例如 `[0.42, 0.58]`。看不清近端、平面图尚未生成或无法确定落点时，省略或用 `null`，排版采用默认位置。此字段用于定位标线，通道宽度仍来自 `dimensions.A.value`。

### 材料与部件术语

| 可见线索 | 可用名称 | 材质描述写法 |
| --- | --- | --- |
| 大块平面、弧顶、双页或分片的硬质背景轮廓 | 背景板、异形景片、弧形门架、立体书本背景 | 描述形状、哑光或亮面和可见拼接，如「奶白哑光弧顶，基材待确认」 |
| 有折痕、垂坠、高光或透光的面层 | 布幔、垂挂帘、透纱 | 描述颜色、褶量与透光度，如「浅杏细褶，半透」 |
| 成团或分枝的花叶，在两侧、地面或背景固定处出现 | 主花艺、侧花簇、地排花艺、悬挂花艺 | 描述花型、叶材轮廓和疏密，如「暖白圆瓣花搭配窄叶，左高右低」 |
| 抬高的踏面，或带可见边口的平面 | 地台、台面、台阶、台口 | 描述台面色泽、边缘和层次，如「象牙白平面，薄边收口」 |
| 从前景通向主体的铺饰 | 路引花境、过道地毯、花瓣通道 | 描述连续面及边缘，如「白色花瓣铺面，两侧低花」 |
| 观礼区座椅和入口标识 | 竹节椅、迎宾牌、迎宾画架 | 描述轮廓、色系和配置，如「棕色竹节造型，白色椅背饰带」 |
| 容器、底座或可见支撑物 | 花器、花柱、基座、外露支架 | 描述轮廓和表面，如「浅色圆柱，哑光表面」 |
| 可辨认的灯体或灯串 | 点光灯、灯带、串灯 | 描述可见位置和光色，如「背景底部暖白点光」 |

### 五步名称和可画状态

常规顺序为场地放样 → 背景定位 → 主体装饰 → 花艺布置 → 通道与座椅。依原图结构调整名称和工序，保持恰好五步。步骤简述用动词配明确部位。统一机位和取景，把第一步的空场地与虚线范围逐步推进到第五步的整体可见场景。每步写明本步保留及新增的内容。看不见的五金、背撑、人员和施工动作留在图外。
